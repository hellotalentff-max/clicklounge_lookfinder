# Find My Look — Look Lab recommendation quiz

A guided quiz that recommends a Look Lab session, collects the client's top / bottom / shoe size and inspiration photos, and sends them to the studio.

- Prices and inclusions load from `clicklounge_looklab/looklab-data.js` (the live Look Lab), so there is no second copy to keep in step.
- Answers, sizes and photos are saved through the POS Apps Script action `saveLookLabInquiry`.
- Page: `index.html`
